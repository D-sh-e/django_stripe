# Stripe Django

Проект Django + Stripe для создания платежных форм.

Поддерживает **Checkout Session** и **Payment Intent**.

Цена товара хранится в долларах (USD) и автоматически конвертируется в центы для Stripe.

## Проект на Render
Проект запущен на сервисе Render и его можно найти по ссылке:
https://django-stripe-dnfs.onrender.com/

На главной странице будет отображаться список всех товаров с ссылками на страницу товара для оплаты

## Быстрый старт (локально)

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/D-sh-e/django_stripe.git
cd stripe_project
```

### 2. Создайте виртуальное окружение и установите зависимости

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Создайте файл `.env`

Создайте файл `.env` по образцу `.env.example` и заполните свои Stripe-ключи (тестовые).


### 4. Примените миграции и создайте суперпользователя

```bash
python manage.py migrate
python manage.py createsuperuser
```

### 5. Запустите сервер разработки

```bash
python manage.py runserver
```

После запуска:

- Перейдите в админку (`/admin`) и добавьте несколько товаров (`Item`).
- Цена указывается в долларах (например, `1.99`).
- На главной странице будет отображаться список всех товаров с ссылками  на страницу товара для оплаты.




## Основные эндпоинты

| URL | Описание |
|---|---|
| `/` | Главная страница со списком товаров |
| `/item/<id>` | Страница товара с кнопкой «Купить» (Checkout Session) |
| `/buy/<id>` | Возвращает `session.id` и `url` для редиректа на Stripe Checkout (используется в `/item/<id>`) |
| `/payment-intent/<id>` | Страница со встроенной оплатой через Payment Element |
| `/success/` | Страница после успешной оплаты |
| `/cancel/` | Страница при отмене оплаты |

## Данные карты для тестирования Stripe

Номер карты - 4242 4242 4242 4242
Срок действия — любая будущая дата (например: 01/50)
CVC — любые 3 цифры (например: 123)
